# AGENTS.md - WallpaperCropFixer App Module

Agent-neutral startup router for the Android `app` module. Root `ENGINEERING.md` and root `AGENTS.md` remain authoritative for safety, verification, deletion, scope, and truthfulness.

## Startup

1. Read `C:\Workspace\ENGINEERING.md`.
2. Read `C:\Workspace\AGENTS.md`.
3. Read `C:\Workspace\Project_Android\WallpaperCropFixer\PROJECT_CONTEXT.md`.
4. Read `PROJECT_CONTEXT.md` in this directory.

## Local Rules

- Parent `PROJECT_CONTEXT.md` is the canonical app context.
- Wallpaper crop behavior, ML Kit image labeling, media permissions, billing, and release behavior are high-risk.

## Verification

Run Gradle commands from the parent app root.
